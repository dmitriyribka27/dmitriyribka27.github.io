Не концепт. Работающие экраны.

Три вида настоящего MONO Finance: главная, аналитика и добавление операции. Для публичного портфолио эти скриншоты обработаны: суммы и другие личные значения заменены на демонстрационные. Оригинальная финансовая база нигде не подключена.

ЗАДАЧА / РЕШЕНИЕ / СТАТУС

Не просто записывать расходы. Понимать, сколько действительно свободно.

MONO Finance вырос из личной потребности видеть остатки, резервы и будущие обязательства в одном месте. Я спроектировал сценарии, интерфейс и финансовую логику, организовал AI-assisted разработку и проверял работу на iPhone.

Реализованы учёт по валютам, операции между счетами, планы платежей, финансовые цели, быстрый ввод и аналитика. Приложение работает локально, без доступа к банковским аккаунтам. Публичный макет выше использует только вымышленные значения.
