## ПОСЛЕДНЕЕ

**2026-11-12 — анимация чтения текста в блоке «Привет, я Дима» на главной.**

- **Изменены:** `brand-site.js`, `brand-site.css`. HTML и формулировки не менялись.
- **Как работает:** скрипт ищет `.about-copy > p`, разбивает текст на декоративные `.reading-word` / `.reading-char` с сохранением inline-подсветки `.lime` и `aria-label` исходного абзаца. `IntersectionObserver` запускает/останавливает таймер при видимости секции. Каждые ~90 мс перемещается подсветка окна букв (радиус 5), между абзацами есть паузы; CSS даёт кратковременный белый/лаймовый glow и тонкий `-webkit-text-stroke`. Отключено при `prefers-reduced-motion`.
- **Коммиты:** CSS `5449ec47a3d51f5884e5bd66de47dec7b4cacf3c`, JS `133c80da8980bd6166ac063f6cdce5b477f03629`.
- **Проверка:** код записан в репозиторий; пользователь положительно оценил эффект. Автоматического тестирования Safari/iPhone не было. При последующих изменениях текста проверить переносы слов, доступность и производительность на длинных абзацах.
